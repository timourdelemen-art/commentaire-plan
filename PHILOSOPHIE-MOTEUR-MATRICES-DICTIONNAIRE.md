# Moteur philosophique — problèmes, matrices et résolutions

## Principe

Le site organise la philosophie selon trois mouvements :

Sujet → type de problème → structure matricielle → résolution → auteur → citation → exercice.

## 1. Types de problématisation

### Contradiction interne
Une notion contient deux exigences qui semblent incompatibles.

### Condition de possibilité paradoxale
Ce qui rend une chose possible menace ce qu’elle rend possible.

### Auto-référence paradoxale
Une réalité suppose ce qu’elle doit produire.

### Tension entre dimensions constitutives
Une notion exige l’articulation de dimensions opposées.

### Confusion des niveaux
Une contradiction apparaît parce que deux plans différents sont confondus.

## 2. Structures matricielles

- Condition / abolition
- Identité / différence
- Unité / multiplicité
- Dépendance / autonomie
- Limite / dépassement
- Apparence / réalité

## 3. Types de résolution

### Duplication ontologique
La contradiction est résolue par distinction de niveaux de réalité.

### Transformation du rapport
Les termes restent mais leur relation change.

### Renversement
Ce qui semblait obstacle devient condition.

### Déplacement
La question initiale est reformulée.

### Intégration
La contradiction est conservée dans une structure plus complexe.

## Usage dans le site

Cette couche doit rester un moteur interne reliant :

- les annales ;
- les problèmes philosophiques ;
- les auteurs ;
- les citations ;
- les exercices.

Elle n'est pas affichée comme un cours supplémentaire à l'élève mais comme une architecture de navigation et de recommandation.
