Mode Bac.

Ici, l’échafaudage disparaît. Vous devez reconstruire seul les gestes appris dans les gammes.

Principe : un texte n’est pas « acquis » parce que vous reconnaissez sa correction. Le geste est acquis lorsque vous le transférez à un texte inconnu.
