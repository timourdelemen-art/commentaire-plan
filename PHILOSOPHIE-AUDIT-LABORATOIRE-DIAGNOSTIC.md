# Audit — Diagnostic + Laboratoire de philosophie

## Objectif
Transformer la richesse accumulée en système visible sans multiplier les rubriques.

## Architecture retenue
Le portail PHILO affiche désormais seulement quatre portes :
1. diagnostic ;
2. laboratoire ;
3. méthode ;
4. annales.

Les pages spécialisées restent accessibles depuis le laboratoire, pas depuis la navigation principale.

## Diagnostic
5 mini-situations :
- problématisation ;
- argumentation ;
- transition ;
- troisième partie ;
- référence.

Fonctionnement :
- 100 % local, sans IA ;
- pas de note ;
- une priorité de travail ;
- si les cinq gestes résistent, renvoi vers une annale complète.

## Laboratoire
Un espace filtrable unique :
- problématiser ;
- argumenter ;
- construire une partie ;
- transitions ;
- troisième partie ;
- références ;
- textes ;
- annales.

20 entrées d’exercice, toutes reliées aux ateliers existants.

## Validation de corpus
La méthode courte a été testée sur 50 sujets d’annales répartis entre art, langage, liberté, technique, temps, droit, échanges, morale et perception.

Résultat :
le noyau « proposition forte → conséquences → coût → problème » tient, mais la première proposition change selon la forme du sujet :
- réponse ;
- explication ;
- critère ;
- condition ;
- fonction ;
- détermination conceptuelle.

Cette nuance a été intégrée à la page méthode.

## SEO / pollution
Décision :
- pas de prolifération de pages visibles dans le menu ;
- profondeur conservée par un laboratoire unique ;
- pages spécialisées gardées parce qu’elles correspondent à de vraies opérations pédagogiques distinctes ;
- navigation simplifiée.

## Audit technique
- aucun lien interne manquant ;
- sections HTML équilibrées ;
- JavaScript valide pour navigation, laboratoire et diagnostic ;
- sitemap : 63 URL, aucune URL sans fichier correspondant.

## Conclusion
L’intégration est retenue : elle augmente la profondeur pédagogique tout en diminuant la sensation de dispersion du site.
