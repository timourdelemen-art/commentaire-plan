# Audit — pensée autonome, références et identité des exercices

## 1. Didactique

### Question
Chaque activité entraîne-t-elle une opération réelle de philosopher plutôt qu’une forme scolaire vide ?

### Résultat
Oui, avec quatre familles :
- produire ;
- diagnostiquer ;
- réparer ;
- transférer.

Les nouveaux ateliers isolent notamment :
- pensée autonome avant auteur ;
- raison vs argument d’autorité ;
- objection forte ;
- exemple qui oblige à conceptualiser ;
- citation utile vs décorative ;
- choix citation/paraphrase ;
- position de la référence dans le raisonnement ;
- reprise de la main après la référence ;
- transition nécessaire ;
- plan non interchangeable ;
- troisième partie la plus forte.

## 2. Principe « penser par soi-même »

Test adopté :
**si l’on retire le nom du philosophe, le raisonnement doit encore tenir.**

La référence intervient ensuite pour :
- préciser ;
- distinguer ;
- renforcer ;
- objecter ;
- déplacer ;
- résoudre.

Elle ne doit jamais être la raison elle-même.

## 3. Marketing pédagogique

Chaque exercice doit être identifiable par un titre bref et mémorable sans transformer le site en jeu superficiel.

Noms retenus :
- Zéro auteur ;
- Une raison, pas un nom ;
- Qui pense ici ? ;
- Sauvez cette citation ;
- Reprenez la main ;
- Quelle problématique survivra ? ;
- Duel de transitions ;
- Bataille des III ;
- Plan interchangeable ?

Critère :
le titre donne envie d’essayer ; la consigne reste sobre ; l’exigence philosophique demeure forte.

## 4. Sources didactiques prises en compte

- modèle de Michel Tozzi : problématiser, conceptualiser, argumenter comme processus interdépendants ;
- rapports de jury : précision des références, refus du catalogue, nécessité d’approfondir moins de références plutôt que d’en accumuler ;
- cadre du bac : construction d’un problème, raisons explicites, transitions, réflexion conduite par le candidat.

Références détaillées dans `PHILOSOPHIE-DIDACTIQUE-PENSEE-REFERENCES.md`.

## 5. IA / sans IA

Principe inchangé :
- toute activité fondamentale fonctionne sans IA ;
- correction locale pour tâches fermées ;
- IA seulement comme diagnostic de production ouverte après tentative ;
- pas de suggestion automatique d’auteur à placer ;
- pas de rédaction du plan, de la transition ou du III à la place de l’élève.

## 6. Architecture

Ajouts :
- `philosophie-penser-par-soi-meme.html`
- `philosophie-references.html`
- enrichissement du laboratoire de dissertation ;
- intégration navigation, accueil, espace enseignants, plan du site et sitemap.

## 7. Audit technique

Contrôles réalisés :
- aucun lien interne manquant sur les pages modifiées ;
- balises de sections équilibrées ;
- syntaxe JS de navigation valide ;
- 61 URL du sitemap vérifiées contre les fichiers du dépôt ;
- aucune URL du sitemap sans fichier correspondant.

## Décision

Intégration retenue : les pages nouvelles renforcent à la fois l’autonomie philosophique et l’identité éditoriale du site sans ajouter une nouvelle couche de jargon méthodologique.
