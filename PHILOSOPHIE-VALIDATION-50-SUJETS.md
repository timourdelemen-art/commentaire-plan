# Validation de la méthode sur 50 sujets d’annales

## But

Éprouver le modèle court :

**réponse plausible → raisons → conséquences → coût / manque → problème**

sur un échantillon volontairement diversifié du recueil académique de 2 366 sujets de dissertation du baccalauréat (1996–2025).

Source : Académie de Montpellier, *Recueil des sujets de dissertation de l’épreuve de philosophie au baccalauréat, 1996–2025*.

L’objectif n’est pas de fabriquer 50 corrigés mais de vérifier si la méthode sait démarrer le travail sans forcer artificiellement les sujets.

## Échantillon

50 sujets répartis entre :
- art ;
- langage / liberté ;
- technique / temps ;
- droit / échanges ;
- morale / perception.

Les formes testées comprennent :
- peut-on / est-il possible ;
- faut-il / doit-on ;
- X est-il Y ;
- X suffit-il à Y ;
- pourquoi ;
- à quoi / à quelles conditions ;
- y a-t-il ;
- formes négatives ou restrictives ;
- questions de dépendance, de finalité et de critère.

## Résultat général

Le modèle tient sur les 50 sujets à condition de ne pas confondre **réponse plausible** avec **réponse oui/non**.

Pour certaines formes, la première « réponse » prend une forme différente :
- **Pourquoi X ?** → première explication plausible ;
- **À quoi reconnaît-on X ?** → premier critère plausible ;
- **À quoi bon X ?** → première fonction ou valeur plausible ;
- **À quelles conditions X ?** → première condition nécessaire ;
- **Y a-t-il X ?** → premier critère d’existence ou d’identification ;
- **Qu’est-ce que X ?** → première détermination conceptuelle forte.

Le cœur demeure identique : **construire une proposition forte, la pousser, voir ce qu’elle ne peut plus préserver, transformer ce manque en problème.**

## Conclusions pour la méthode du site

### 1. Le noyau est validé
Sur les 50 cas, on peut toujours produire une **première proposition sérieuse**, puis la pousser jusqu’à une difficulté interne.

### 2. Le formulaire grammatical n’est pas la méthode
« Peut-on », « faut-il », « suffit-il », etc. sont des **indicateurs d’entrée**, jamais des générateurs automatiques de plan.

### 3. Six sous-routines suffisent pour les formes atypiques
- réponse ;
- explication ;
- critère ;
- condition ;
- fonction ;
- définition / détermination.

Toutes retombent ensuite sur :
**pousser → coût → problème.**

### 4. Le meilleur exercice n’est pas toujours la production libre
Pour certaines opérations, le diagnostic par distracteurs est plus efficace au début :
- reconnaître une fausse alternative ;
- repérer une simple reformulation ;
- distinguer une condition nécessaire d’une condition suffisante ;
- éliminer une problématique qui change de notion.

### 5. La transition est confirmée comme micro-problématisation
À l’échelle du devoir :
**réponse → manque → question**.

À l’échelle du sujet :
**réponse plausible → coût → problématique**.

Même opération logique, deux échelles.

## Décision

La méthode ultra-courte peut rester au centre du site. Elle doit seulement afficher clairement que la « réponse plausible » change de forme selon le sujet : réponse, explication, critère, condition, fonction ou détermination conceptuelle.
