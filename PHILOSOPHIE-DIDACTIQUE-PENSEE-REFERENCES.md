# Philosophie — principes didactiques pour penser, argumenter et mobiliser les références

## 1. Principe directeur

La dissertation doit rester un raisonnement conduit par l’élève.

Une référence philosophique n’est pas :
- une preuve par autorité ;
- un nom placé pour montrer une culture ;
- un résumé doctrinal autonome ;
- une substitution à l’argument.

Elle devient utile lorsqu’elle répond à un besoin déjà produit par le raisonnement de l’élève :
- préciser un concept ;
- fournir une distinction ;
- renforcer une raison ;
- construire une objection ;
- déplacer un problème ;
- proposer une opération de résolution.

Formule pédagogique :

**ma pensée → mes raisons → besoin précis → référence → analyse → ce que j’en conclus**

## 2. Appuis didactiques

### Michel Tozzi
Le modèle didactique du philosopher articule trois processus interdépendants :
- problématiser ;
- conceptualiser ;
- argumenter.

Intérêt pour le site :
- on peut isoler temporairement une opération pour la faire travailler ;
- mais l’exercice doit ensuite être réinvesti dans le mouvement complet d’une pensée ;
- l’objectif n’est pas de produire des automatismes rhétoriques mais une capacité transférable.

Sources :
- https://www.philotozzi.com/1996/09/michel-tozzi-un-modele-didactique-du-philosopher/
- https://www.philotozzi.com/2006/10/enseigner-la-problmatisation-ou-plutt-apprendre-problmatiser/
- https://www.persee.fr/doc/enphi_0986-1653_1995_num_46_2_15504

### Rapports de jury
Les rapports de concours insistent régulièrement sur :
- la précision des références ;
- la nécessité de ne pas accumuler les auteurs ;
- l’approfondissement plutôt que le catalogue ;
- la construction effective du problème et du raisonnement.

Sources :
- https://www.devenirenseignant.gouv.fr/sujets-et-rapports-des-jurys-concours-du-capes-de-2025-1439
- https://www.devenirenseignant.gouv.fr/sujets-et-rapports-des-jurys-concours-de-l-agregation-de-2026-1659

### Épreuve du baccalauréat
Le cadre de l’épreuve exige un problème, un raisonnement ordonné, des transitions, des raisons explicites et une conclusion justifiée. Les connaissances doivent être mobilisées dans la réflexion plutôt que récitées.

Source :

## 3. Batterie d’exercices

### A. Penser par soi-même
1. zéro auteur : réponse + raison + exemple + difficulté ;
2. remplacer le nom d’auteur par une raison ;
3. construire l’objection la plus forte à sa propre thèse ;
4. faire d’un exemple une épreuve du concept ;
5. supprimer le philosophe d’un paragraphe et vérifier si le raisonnement tient ;
6. comparer « catalogue d’auteurs » et « pensée qui mobilise un auteur ».

### B. Mobiliser une référence
1. sauver une citation brute ;
2. utile ou décorative ;
3. citation ou paraphrase ;
4. remettre la référence au bon endroit dans le raisonnement ;
5. test de remplacement de l’auteur ;
6. même référence, deux sujets ;
7. trois références, une seule vraiment pertinente ;
8. reprendre la main après la citation.

### C. Problématiser
1. produire ;
2. sélectionner ;
3. éliminer des distracteurs ;
4. réparer ;
5. transférer.

### D. Construire le plan
1. réponse / nécessité / limite ;
2. test de permutation ;
3. partie → manque → transition ;
4. duel de transitions ;
5. I + II → reste ;
6. bataille des III ;
7. test de conservation du III.

## 4. Typologie des erreurs à transformer en distracteurs

### Problématique
- trop générale ;
- simple reformulation ;
- fausse alternative ;
- présupposé non interrogé ;
- contradiction artificielle ;
- hors sujet partiel ;
- notion remplacée par une autre ;
- difficulté extérieure à la réponse construite.

### Transition
- résumé ;
- annonce scolaire ;
- changement de thème ;
- question trop générale ;
- question déjà résolue ;
- manque sans rapport avec la partie.

### Référence
- nom propre décoratif ;
- citation sans analyse ;
- paraphrase vague ;
- argument d’autorité ;
- auteur interchangeable ;
- référence exacte mais hors fonction ;
- récitation doctrinale trop longue ;
- contresens d’usage.

### Troisième partie
- compromis mou ;
- retour à I ;
- répétition de II ;
- nouvelle idée sans nécessité ;
- suppression arbitraire d’un terme ;
- élargissement hors sujet ;
- résolution qui ne conserve rien des acquis.

## 5. Principe marketing

Le nom de l’exercice doit rendre visible l’opération sans alourdir la consigne.

Exemples retenus :
- Quelle problématique survivra ?
- Trouvez la faille.
- Duel de transitions.
- Bataille des III.
- Qui pense ici ?
- Sauvez cette citation.
- Zéro auteur.
- Remplacez l’auteur.
- Reprenez la main.

Règle :
**titre mémorable + consigne extrêmement simple + exigence intellectuelle forte.**

## 6. IA / sans IA

Toute opération essentielle reste faisable sans IA.

Correction locale préférée pour :
- choix ;
- classement ;
- puzzle ;
- distracteurs ;
- comparaison ;
- auto-audit.

IA utile pour :
- production ouverte ;
- diagnostic de précision ;
- repérage du manque principal ;
- question de reprise.

L’IA ne doit pas :
- proposer l’auteur à placer ;
- écrire le plan ;
- produire la transition ;
- fournir le III ;
- rédiger le paragraphe avant la tentative de l’élève.

## 7. Critère final d’intégration

Un exercice n’entre sur le site que s’il passe les deux tests :

### Didactique
Rend-il l’élève plus capable de penser seul et de transférer l’opération ?

### Marketing
Son titre, son exemple et sa consigne donnent-ils envie de l’essayer immédiatement ?

Si un seul des deux échoue, l’exercice doit être remanié.
