Travaillez un geste.
Puis jouez le morceau.

Un commentaire mobilise plusieurs opérations à la fois. Ici, vous les entraînez séparément avant de les recombiner sur un texte inconnu.

Principe : l’aide disparaît progressivement. Vous regardez, choisissez, complétez, construisez, puis transférez.

La progression

Une aide qui disparaît.

JE REGARDE → JE CHOISIS → JE COMPLÈTE → JE CONSTRUIS → JE TRANSFÈRE

Le but n’est pas de réussir longtemps avec une méthode sous les yeux. Le but est de ne plus en avoir besoin. Chaque gamme conduit donc vers une tâche où l’échafaudage est retiré.

PARCOURS COMPLET

Les gammes ne sont pas sept chapitres isolés.

Elles se combinent dans une progression : voir → choisir → justifier → compléter → construire → transférer. Le dernier critère est toujours le même : pouvez-vous refaire le geste sur un texte inconnu ?
