ŒUVRES INTÉGRALES

Lire quelques passages.
Construire toute l’œuvre.

Chaque œuvre est travaillée à partir d’extraits soigneusement choisis, puis reliée par des exercices transversaux. Le but n’est pas d’apprendre une fiche : c’est de savoir observer, relier, argumenter et réutiliser.

Deux chemins possibles :
problématique → analyse
ou
analyse → problématique.

Les deux conduisent à la même exigence : prouver par le texte.

SUR CHAQUE EXTRAIT

Construire progressivement le commentaire.

1. Lire le problème

Comprendre ce que le passage met en place, ce qu’il fait attendre et ce qu’il produit pourtant.

2. Observer le texte

Repérer les éléments utiles, les procédés et leur effet précis dans ce passage.

3. Organiser

Regrouper les observations, formuler ce que le texte fait, construire les mouvements puis la problématique ou le plan.

DEUX PARCOURS

Deux façons sérieuses d’entrer dans l’analyse.

Parcours A · Du problème au texte

Choisir ou formuler la problématique → repérer les mouvements → chercher les éléments textuels → nommer les procédés utiles → expliquer les effets.

Parcours B · Du texte au problème

Observer les éléments → procédés → effets → regrouper ce qu’ils permettent de montrer → formuler les grandes idées → faire apparaître la problématique.

Transfert

À la fin, l’élève doit pouvoir refaire seul l’ensemble du raisonnement sur un nouvel extrait.

DANS TOUTE L’ŒUVRE

Construire une vision transversale.

Relier

Comparer des scènes, suivre un personnage, un motif, un lieu, une image ou une évolution.

Argumenter

Associer passage → citation → analyse → argument pour préparer la dissertation.

Mémoriser utile

Construire une petite banque de citations exactes et polyvalentes, avec ce qu’elles permettent vraiment de prouver.
